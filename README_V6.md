# Nomeraa Premium V6

Полная переработка приложения после анализа записи экрана.

## Что исправлено
- Убрано смешение светлой и тёмной тем: все экраны, листы и карточки теперь тёмные.
- Убраны старые белые модальные окна терминала, рынка и экономики.
- Исправлена навигация: активный пункт всегда соответствует открытому разделу.
- Приложение переписано как единая мобильная SPA-структура, поэтому исчезли ошибки порядка загрузки DOM/JS.
- Service Worker переведён на network-first для навигации, чтобы GitHub Pages не показывал старые сборки.
- Ежедневные задания теперь реально сбрасываются по дате.
- Аукцион работает по таймеру: ставка пользователя не считается мгновенной победой, NPC могут перебить, победа рассчитывается в конце.
- Убрана лишняя валюта «коины» и выбор наличные/карта: экономика теперь строится вокруг наличных, репутации и уровня.
- Исправлен главный экономический дисбаланс прошлой версии: автомобили больше не дают мгновенную прибыль при покупке.

## V6.1 — iPhone cache fix
Запись экрана показала, что установленная иконка iPhone всё ещё запускала старый V5-интерфейс,
хотя в репозитории уже лежал V6. Это кэш установленного PWA / старый Service Worker.

После загрузки V6.1:
1. В Safari открыть `/Nomeraa/reset.html`.
2. Нажать «Очистить кэш и открыть V6.1».
3. Проверить, что в шапке написано PREMIUM · V6.1.
4. Удалить старую иконку Nomeraa с домашнего экрана.
5. В Safari: Поделиться → На экран «Домой» → Добавить.

`reset.html` удаляет Cache Storage и Service Worker, но не удаляет игровой localStorage.


## V6.2 — анимация и анти-спам
Что изменено:
- Полностью переделана анимация прокрутки номера: больше шагов, более плавное торможение, визуальный blur/overshoot, динамическая подсветка рамки номера.
- Добавлены разные звуки по редкости:
  - обычный результат — короткий спокойный сигнал;
  - rare — лёгкий двойной chime;
  - epic — более длинная трёхтональная fanfare;
  - special — отдельная яркая fanfare.
- Добавлены визуальные эффекты при редких номерах: вспышка рамки, цветовая подсветка и разлетающиеся sparks.
- Исправлен спам по кнопке создания номера:
  - генерация блокируется на всё время анимации;
  - действует короткий debounce/cooldown после прокрутки;
  - временно блокируются также связанные действия генератора, чтобы нельзя было ломать состояние повторными нажатиями.
